👋 What Is vitalaize?

vitalaize is a small desktop application for Windows. It turns your screen into a live wall display. On that display you can see what is happening with your Claude Code sessions, your Codex sessions, and the builds that run from your GitHub projects.

You do not need to be a programmer to use it. If you can open an app on your computer, you can use vitalaize. The app is made for people who want to keep an eye on activity without constantly clicking between browser tabs and terminal windows.

Think of it like a noticeboard for your computer work. Everything important is on one surface, easy to read from a distance, and easy to understand at a glance.

🛠️ Common Questions

Do I need to install anything else first?

No. vitalaize is a self-contained application. Download it, run it, and it handles the rest.

Where do I get updates?

New versions are posted on the same releases page. Bookmark the link so you can check back whenever you want the latest version. Updating means downloading the newest file and running it the same way you did the first time.

What if the screen looks empty?

vitalaize shows information once there is something to show. If your sessions or builds are quiet, the screen will look quiet too. As soon as activity starts, it appears on the wall screen.

Can I use it on more than one computer?

Yes. You can download and set up vitalaize on each Windows computer where you want a wall screen.

Does it change anything on my GitHub account?

vitalaize is a display tool. It shows you information. It is not designed to edit your projects or change your account settings.

💡 Tips for the Best Experience

  • Use a screen that stays on and stays visible, such as a spare monitor or a wall-mounted display.
  • Turn off automatic sleep for that display so the wall screen does not go dark while you need it.
  • Keep the vitalaize window in full-screen mode for the cleanest look.
  • Sit back and glance at it the way you would glance at a clock. That is the whole idea.
